HTML Fundamentals

What is HTML?

HTML is de taal die een browser leest om een webpagina te laten zien.

What are HTML-Elements?

HTML-elementen gebruik je om aan te geven wat er op een webpagina moet komen.

What is a tag?

Een tag geeft aan wat een element is. Meestal heb je een opening tag en een closing tag.

How does the browser use HTML to create what I see?

De browser leest de HTML-code en laat daarna de webpagina zien.

What are the basic HTML-Elements?

De elementen die we hebben geleerd zijn html, head, body, p, span, div en h1 tot h6.

A-tag

De a-tag gebruik je om een link te maken. Met href geef je aan waar de link naartoe gaat.

Img-tag

De img-tag gebruik je om een afbeelding te laten zien. Met src geef je aan waar de afbeelding staat.
